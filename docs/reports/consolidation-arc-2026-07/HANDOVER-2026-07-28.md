## 4. Method that worked (keep it)

Every fix proved its test could fail — write it, watch it RED, fix, watch GREEN, record both. Add a
**negative control** wherever "refuse everything" would also pass; several real defects were caught
only by that. Verification **gates** the merge, it does not race it: an independent adversarial
reviewer reverts the fix and confirms the test goes red. That pass **refuted** one MR outright
(!225's help content misdescribed the console in five places and one test was vacuous) and forced
an honesty fix on another (!231 claimed more than it scanned).

The recurring defect class remains **a check that cannot fail**. New instances found this session:
a bats `! grep -q` that asserts nothing; a gate greping the wrong subtree; a `[ -f ]` that cannot
distinguish absent from unreadable; `yq '… | type'` returning `!!null` for a missing key; a
DONE-WHEN criterion that matched a symbol's *name* while the symbol had zero callers.

**Conflict resolution on structured files is not textual.** `contracts.sh` gained two independent
verbs at the same insertion points with near-identical boilerplate; git aligned them as one
function, so keep-both would have produced a Frankenstein verb that reads fine and is tested by
nothing. Resolved structurally (take main's file, re-apply the other side's diff), then **proved it
with both suites** (30 ok / 0 not ok) — the machine check, not the eyeball.
