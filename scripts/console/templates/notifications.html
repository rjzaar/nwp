Set up your phone

  1. Put the phone on the mesh: install the Tailscale app and join it to the same Headscale network (pl console enroll prints the pre-auth key runbook). Push only arrives while the phone is connected — see the caveat below.
  2. Install Gotify (F-Droid or Play Store; the client is open source).
  3. Open it and sign in against {{ status.url or 'http://<tailnet-ip>:8080' }} with your Gotify user account — not the application token.
  4. Tap Send test notification above and confirm it lands.

Caveat, stated plainly: Gotify holds a WebSocket open from the phone, so a notification is only delivered while the phone can actually reach the server. Off the mesh (or with Tailscale toggled off to save battery) messages queue on the server and arrive when you reconnect — they are not lost, but they are not timely either. This channel is "tell me now"; the durable record stays in the console audit log and GitLab.

Full runbook, including provisioning the 0600 application token on the console host: docs/guides/console-notifications.md.
